# Credits and rights

LUMON OS XL is an unofficial firmware extension by
[DataBeat — Michele Ibba](https://micheledatabeat.github.io/) for the
first-generation Korg Volca Sample.

## What this repository contains

Documentation only. It contains **no Korg firmware, no LUMON OS XL updater or
image and no code**. LUMON OS XL is installed with
[Volca Studio XL](https://github.com/MicheleDataBeat/volcastudio-xl-releases),
which builds it on the user's computer from the user's own copy of Korg's
official *volca sample System Updater 1.42*, downloaded from Korg under Korg's
software licence agreement.

## Korg firmware

LUMON OS XL is based on Korg's firmware 1.42. Korg retains its rights in the
original firmware and documentation. Volca Studio XL contains only LUMON's own
changes and applies them to the user's copy; neither this repository nor Volca
Studio XL distributes Korg firmware.

## Pajen

Credit goes to **Pajen** for his pioneering Volca firmware work. BETA7's bar
filtering, probability, extended-menu workflow and exposure of native reverb
choices informed LUMON's research and design. XL uses the Korg 1.42 image,
rather than the BETA7 image, as its firmware base. This is not a claim of
clean-room development or a complete authorship audit.

[Pajen's BETA7 announcement](https://www.reddit.com/r/synthesizers/comments/fpxa1c/)
· [BETA7, hosted by Ranzee](https://ranzee.com/volca-sample-unofficial-firmware/).
Ranzee hosts the file; the firmware author is Pajen.
